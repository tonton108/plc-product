# モーション・インタラクションガイドライン

## ポリシー
- アニメーションは「状態変化をわかりやすくするため」にのみ使う
- 見せびらかすための派手なモーションは禁止
- 工場現場での長時間使用を考慮し、目が疲れないアニメーションを優先する

## アニメーション
- 基本のトランジション時間: 120–200ms 程度
- イージング: ease-out / ease-in-out を使い、バウンスやオーバーシュートは避ける
- ホバー・フォーカス時は「色のトーン変化 + わずかなシャドウ」のみ
- ローディングはスピナーよりもプログレスバーや簡易なスケルトン UI を優先する

## 状態のフィードバック
- ボタン押下後は、即座にローディング状態 or 成功状態を視覚的に返す
- PLC 接続状態の変化（接続中 → 稼働中 → エラー）は、色とアイコンの両方で示す
- 画面全体がガタガタ動くようなレイアウトアニメーションは避ける

## リアルタイムデータ更新
- **Chart.js でのデータ更新:**
  - canvas 要素のみを更新し、カード全体を再描画しない
  - データ追加時のアニメーション時間: 300ms 程度
  - スムーズなライン描画を優先（linear interpolation）

- **ステータスカードの更新:**
  - 数値変化時は、古い値から新しい値へのカウントアップアニメーション（500ms）
  - 背景色変化（正常→エラーなど）は 200ms で fade

## タッチインタラクション（ラズパイ）
- タップ時は ripple エフェクトで視覚的フィードバック
- ボタンの active 状態は 100ms で表示（押している感を出す）
- スワイプ・ドラッグ操作では、指の動きに追従する即座のフィードバック

## ローディング状態
- API リクエスト中: ボタン内にスピナー表示（ボタン全体は disabled）
- ページ遷移: 100ms 以上かかる場合はプログレスバーを表示
- データ取得中: スケルトン UI（カードの形を保ちつつ、グレーのプレースホルダー）

## 避けること
- 1秒以上かかるアニメーション
- 複雑な 3D トランスフォーム、パララックス効果
- 自動再生される動画・GIF アニメーション
- 無限ループするアニメーション（ローディング以外）
- ページロード時の派手なエントランスアニメーション
