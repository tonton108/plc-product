# PLC 監視システム 共通デザインガイドライン

## 全体方針
- 工場現場で使う業務アプリとして、落ち着いていて視認性が高い UI を優先する
- 「AI っぽい派手さ」よりも「信頼感・安定感」を重視する
- ラズパイ側はタッチ操作前提で、要素大きめ・情報密度低め
- 中央サーバー側ダッシュボードは情報量多めだが、1画面に詰め込みすぎない

## 避けること
- フォント: Inter, Roboto, Open Sans は使わない
- 原色に近い派手な紫 (#a855f7 系) と安易なグラデーションを使わない
- ガラスモーフィズム、ネオモーフィズム、過剰なシャドウなど「AI が好みそうな」装飾は使わない
- カラフルなレインボー配色や意味のないアイコン乱用は避ける

## レイアウト
- 4 / 8 / 12 カラムベースのグリッドを意識してコンポーネントを並べる
- 余白 (padding / margin) は十分にとり、要素同士を詰め込みすぎない
- セクションごとにカード or パネルでブロック化して情報のグルーピングを明確にする
- ラズパイ画面はボタン・カードを「指で押しやすいサイズ」（縦横 44px 以上）にする

## 表現トーン
- 角丸は中程度（例: 8–12px 程度）に統一し、極端な丸ボタンや角ばりすぎも避ける
- アイコン＋テキストを基本とし、アイコンだけで意味が伝わらない UI は作らない
- 状態変化（正常・注意・異常）は色だけでなくラベルやアイコンでも伝える

## プロジェクト固有の注意点
- Vuetifyのツールチップは必ず `content-class="tooltip-custom"` を使用してダークモードでの視認性を確保する
- リアルタイムデータ更新では、canvas要素のみを更新してカード全体を再描画しない
- エラー・アラーム表示では、色分けだけでなくアイコンとテキストで状態を明確にする
