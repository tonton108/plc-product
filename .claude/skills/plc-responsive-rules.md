# レスポンシブ対応の基準

このガイドラインは、PLC監視システムが動作する各デバイスでの表示最適化ルールを定義します。

## ブレークポイント

### ラズパイタッチスクリーン
- **解像度:** 800x480 ～ 1024x600
- **想定用途:** 現場での設備個別監視・設定
- **インタラクション:** タッチ操作のみ

### 中央サーバー PC
- **解像度:** 1280px～（主に 1920x1080）
- **想定用途:** 全設備の一覧監視・管理
- **インタラクション:** マウス・キーボード

### タブレット（オプション）
- **解像度:** 768px～1024px
- **想定用途:** モバイル監視（現場巡回時）
- **インタラクション:** タッチ操作

### スマホ（オプション）
- **解像度:** ～767px
- **想定用途:** 緊急時の状態確認
- **インタラクション:** タッチ操作

## 優先デバイス

**開発・テスト時の優先順位:**
1. ラズパイタッチスクリーン（最優先）
2. 中央サーバー PC（次点）
3. タブレット（オプション）
4. スマホ（オプション）

## デバイス別の UI 調整

### ラズパイタッチスクリーン

**レイアウト:**
- 1カラムレイアウトが基本
- カードは縦に積む（横並びは最大2列まで）
- ナビゲーションはボトムナビゲーション or ハンバーガーメニュー

**タッチターゲット:**
- ボタン・カードの最小サイズ: 44px x 44px
- アイコンボタン: 48px x 48px 以上
- リストアイテム: 最低 56px の高さ

**フォントサイズ:**
- 見出し: 24px～32px
- 本文: 16px～18px
- ボタンラベル: 16px～20px

**その他:**
- ホバーエフェクトは無効化（タッチデバイスのため）
- ripple エフェクトで視覚的フィードバック
- スクロール可能な領域は明確に示す

### 中央サーバー PC

**レイアウト:**
- 12カラムグリッドシステム（Vuetify の v-row / v-col）
- ダッシュボードは 3～4 列のカードレイアウト
- サイドバー（左）+ メインコンテンツ（右）の構成

**インタラクション:**
- ホバーエフェクトでインタラクティブな要素を明示
- キーボードショートカット対応（例: Ctrl+S で保存）
- マウスホイールでのスクロールを最適化

**フォントサイズ:**
- 見出し: 20px～28px
- 本文: 14px～16px
- テーブル: 13px～14px

**その他:**
- 情報密度を高める（1画面に多くの情報を表示）
- データテーブルは固定ヘッダー + スクロール
- 複数のグラフを並べて比較しやすくする

### タブレット（オプション）

**レイアウト:**
- 2カラムレイアウトが基本
- ランドスケープモード（横向き）では PC に近い表示
- ポートレートモード（縦向き）ではラズパイに近い表示

**タッチターゲット:**
- ボタン・カードの最小サイズ: 44px x 44px
- PC とラズパイの中間的なサイズ感

### スマホ（オプション）

**レイアウト:**
- 1カラムレイアウト固定
- 最小限の情報のみ表示（設備一覧、アラート、ステータス）
- 詳細情報は個別ページに遷移

**タッチターゲット:**
- ボタン・カードの最小サイズ: 48px x 48px
- 重要なアクションボタンは画面下部に固定

## Vuetify でのレスポンシブ実装

### ブレークポイント定義

Vuetify のデフォルトブレークポイント:
- xs: < 600px（スマホ）
- sm: 600px ～ 960px（タブレット縦）
- md: 960px ～ 1264px（タブレット横・小型PC）
- lg: 1264px ～ 1904px（PC）
- xl: > 1904px（大型PC）

### 実装例

```vue
<v-row>
  <!-- ラズパイ・スマホ: 12列（全幅）、タブレット: 6列（半幅）、PC: 4列（1/3幅） -->
  <v-col cols="12" sm="6" md="4" v-for="card in cards" :key="card.id">
    <v-card>...</v-card>
  </v-col>
</v-row>
```

### デバイス別の条件分岐

```vue
<template>
  <!-- PC: サイドバー表示 -->
  <v-navigation-drawer v-if="$vuetify.display.mdAndUp" permanent>
    ...
  </v-navigation-drawer>

  <!-- ラズパイ・タブレット: ハンバーガーメニュー -->
  <v-app-bar v-else>
    <v-app-bar-nav-icon @click="drawer = !drawer" />
  </v-app-bar>
</template>

<script setup>
import { ref } from 'vue'
const drawer = ref(false)
</script>
```

## テスト時の確認ポイント

- [ ] ラズパイ解像度（800x480）でレイアウトが崩れないか
- [ ] タッチターゲットが十分な大きさか（44px x 44px 以上）
- [ ] PC画面（1920x1080）で情報密度が適切か
- [ ] タブレット横向きで表示が最適化されているか
- [ ] スマホ縦向きで重要な情報が見えるか
- [ ] フォントサイズがデバイスに応じて適切か
- [ ] 画像・グラフが各解像度で正しく表示されるか
