# カラーパレットガイドライン（ダーク／ライト両対応）

## 共通コンセプト
- 「深いブルーグレー + 落ち着いたグリーン」の工業系モダン UI
- 彩度低め・明度差高めで目が疲れにくい配色にする
- Supabase 風の洗練された雰囲気を参考にしつつ、工場現場向けに調整

## ダークモード（ラズパイ・中央サーバー共通）
- 背景: かなり暗いブルーグレー系 (#020617 ～ #0f172a 付近)
- サーフェス（カード・パネル）: 背景 + 少しだけ明るい色 (#1e293b ～ #334155)
- 主要アクセント: 落ち着いたグリーン (#22c55e 付近) を基調とした成功色
- 情報色:
  - 成功 / 稼働中: グリーン系 (#22c55e, #10b981)
  - 注意 / 警告: アンバー系 (#fbbf24, #f59e0b)
  - 異常 / エラー: ディープレッド系 (#ef4444, #dc2626)
  - 情報ラベル: シアン～ティール系（控えめな彩度）(#06b6d4, #14b8a6)
  - 停止 / 無効: グレー系 (#64748b, #94a3b8)

## ライトモード
- 背景: ごく薄いグレー or 青みがかったホワイト (#f8fafc, #f1f5f9)
- サーフェス: 白ベース (#ffffff) に、境界線は薄いグレーの 1px (#e2e8f0)
- アクセント・状態色はダークモードと共通だが、コントラスト比が十分になるように濃さを調整する
  - 成功: #16a34a
  - 注意: #d97706
  - エラー: #dc2626
  - 情報: #0891b2
  - 停止: #475569

## 避けること
- 紫っぽいアクセントカラー（#a855f7, #c084fc など）と、複雑なグラデーション
- 3 色以上のグラデーション背景
- 意味を持たないカラフルな虹色・ネオンカラー
- 背景とのコントラスト比が不十分な色の組み合わせ（WCAG AA 基準を満たすこと）

## プロジェクト固有の色使い
- **PLCステータス色:**
  - オンライン（稼働中）: グリーン (#22c55e)
  - オフライン（停止中）: グレー (#64748b)
  - エラー（通信失敗）: レッド (#ef4444)
  - 警告（連続エラー）: アンバー (#fbbf24)

- **チャート色:**
  - メインデータライン: ティール (#14b8a6)
  - サブデータライン: シアン (#06b6d4)
  - しきい値ライン: アンバー（破線）
  - エラーマーカー: レッド（点）

- **ツールチップ:**
  - 背景: #424242（ダークモード）/ #f5f5f5（ライトモード）
  - テキスト: #ffffff（ダークモード）/ #212121（ライトモード）
