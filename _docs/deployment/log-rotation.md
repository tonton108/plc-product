# ログローテーション設定ガイド

**作成日:** 2025-01-24

## 概要

ログファイルが無限に大きくなるのを防ぐため、古いログを自動的に「回転（ローテーション）」させて整理します。

---

## 🎯 ログローテーションとは？

**問題:**
- アプリケーションはログを記録し続ける
- 放置すると数GB〜数十GBに膨れ上がる
- ディスク容量を圧迫してシステムが停止

**解決策:**
- 毎日ログファイルをバックアップ
- 古いログは圧縮して容量削減
- 一定期間（7日）経過したログは自動削除

---

## 📊 容量削減効果

| 期間 | ローテーション無し | ローテーションあり（7日保持） |
|-----|-----------------|------------------------|
| 1週間 | 700MB | 70MB（圧縮） |
| 1ヶ月 | 3GB | 70MB（圧縮） |
| 1年 | 36GB | 70MB（圧縮） |

**圧縮効果:** 1年間で 36GB → 70MB（**約500倍**の削減）

---

## ✅ 実装方法（Raspberry Pi）

### 自動ローテーション（推奨・設定不要）

**Raspberry Piエージェントは起動時に自動的にログローテーションを実行します。**

**実装箇所:**
- `plc-dashboard/raspi_agent/log_rotator.py` - ローテーション処理
- `plc-dashboard/raspi_agent/agent_app.py:897-903` - 起動時に自動実行

**動作:**
1. Raspberry Piエージェント起動時に自動チェック
2. ログファイルが1MB以上かつ当日ローテーション未実施の場合に実行
3. `.log` ファイルを `.log.YYYYMMDD.gz` にリネーム＆圧縮
4. 7日以上前のログファイルを自動削除

**追加設定不要:** `python agent_app.py` を実行するだけでOK！

### 起動時の出力例

```
🚀 PLC UI システム起動中...
==================================================
📁 ログローテーションチェック開始
==================================================
🔄 ログローテーション開始: plc_agent.log
   ✅ ローテーション完了: plc_agent.log
   ✅ 圧縮完了: 89.5% 削減
   🗑️  2 個の古いログを削除
✅ 1 個のログファイルをローテーションしました
==================================================
🚀 PLCエージェント起動...
```

### ローテーション条件

以下の**すべて**の条件を満たす場合にローテーション実行：

1. ログファイルが存在する
2. ログファイルサイズが1MB以上
3. 当日まだローテーションしていない

**スキップされる例:**
- ログファイルが存在しない → スキップ
- ログファイルが1MB未満 → スキップ（小さすぎてローテーション不要）
- 今日既にローテーション済み → スキップ

## 🔧 カスタマイズ

### 保持期間の変更

`agent_app.py` の保持期間を変更できます：

```python
# plc-dashboard/raspi_agent/agent_app.py:901
rotate_all_logs(log_dir=current_dir, keep_days=7)  # 7日 → 30日 等に変更可能
```

**推奨値:**
- 開発環境: 3日〜7日
- 本番環境: 7日〜30日
- 重要システム: 30日〜90日

## 🔍 トラブルシューティング

### ログローテーションが実行されない

**原因1: ログファイルが小さい**
```
ログファイルが小さいためスキップ: plc_agent.log (512000 bytes)
```
→ 1MB未満の場合はスキップされます（正常動作）

**原因2: 既に今日ローテーション済み**
```
今日既にローテーション済み: plc_agent.log
```
→ 1日1回のみ実行されます（正常動作）

**原因3: ログファイルが存在しない**
```
ログファイルが存在しません: plc_agent.log
```
→ ログファイルが作成されるまで待ちます

### 古いログが削除されない

**確認:**
```bash
# 古いログファイルの確認
ls -lh /home/pi/raspi_agent/*.log.*

# 日付を確認
date
```

**原因:** 7日以上前のログのみ削除されます

### ディスク容量の確認

```bash
# ディスク使用量確認
df -h

# ログディレクトリのサイズ確認
du -sh /home/pi/raspi_agent/*.log*
```

## 🆚 従来の logrotate との比較

| 項目 | logrotate（従来） | log_rotator.py（新実装） |
|------|------------------|----------------------|
| **設定方法** | `sudo cp ...` でシステム設定 | 設定不要（自動） |
| **実行タイミング** | cron（毎日固定時刻） | アプリ起動時 |
| **権限** | root権限必要 | ユーザー権限でOK |
| **依存関係** | Linuxシステム必須 | Pythonのみ |
| **カスタマイズ** | 設定ファイル編集 | Pythonコード編集 |

**新実装のメリット:**
- ✅ 設定ファイル不要（アプリに組み込み）
- ✅ sudo不要（ユーザー権限で実行可能）
- ✅ アプリ起動時に自動実行（設定忘れ防止）
- ✅ クロスプラットフォーム（Windows開発環境でも動作）
