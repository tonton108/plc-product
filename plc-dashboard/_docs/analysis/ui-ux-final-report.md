## 🔧 実施した修正

### 修正1: PLC設定データ形式の修正

**問題:**
- `demo_data_sender.py`が間違った形式でPLC設定を送信
- 送信: `{"plc_configs": [...]}`（辞書）
- 期待: `[...]`（リスト）
- 結果: PLC設定が空配列`[]`となり、ステータスカードとグラフが動的生成されない

**修正内容:**

**ファイル:** [plc-dashboard/backend/demo_data_sender.py](../../plc-dashboard/backend/demo_data_sender.py:221)

**変更箇所:** line 221

```python
# 修正前
response = requests.put(url, json={"plc_configs": plc_configs}, timeout=5)

# 修正後
response = requests.put(url, json=plc_configs, timeout=5)
```

**修正結果:**
- ✅ PLC設定が正しく登録（5個: 温度、電流、圧力、回転数、振動）
- ✅ ステータスカード5個が正常に表示
- ✅ グラフ5個が正常に表示・リアルタイム更新

---

### 修正2: Playwrightテストスクリプトのセレクタ修正

**問題:**
- ステータスカードの検出セレクタが間違っていた
- `.glass-card`クラスを使用していたが、実際は`.status-card`クラス

**修正内容:**

**ファイル:** [plc-dashboard/scripts/test_ui_ux.py](../../plc-dashboard/scripts/test_ui_ux.py:175-179)

**変更箇所:** line 175-179

```python
# 修正前
status_cards = page.locator('.glass-card').filter(has=page.locator('.v-progress-circular, .text-h4')).all()
if len(status_cards) == 0:
    issues.append("⚠️ モニタリング: ステータスカードが表示されていない")

# 修正後
status_cards = page.locator('.status-card').all()
if len(status_cards) == 0:
    issues.append("⚠️ モニタリング: ステータスカードが表示されていない")
else:
    print(f"  ✅ ステータスカード検出: {len(status_cards)}個")
```

**修正結果:**
- ✅ Playwrightテストでステータスカード5個を正しく検出
- ✅ テスト結果が「すべてのチェックをパス」に変更
